<h1>The Ultimate Solution to get only the newest charts for custom Muse Dash levels!</h1>

<h2>REQUIRES:</h2>

<ul>
  <li>Melon Loader (ver 0.6.1)</li>
  <li>Python 3</li>
  <li>Muse Dash on Steam</li>
  <li>Muse Plus DLC on Steam (or Just as Planned)</li>
</ul>

<p>Will NOT work on MelonLoader v0.6.2. Newer versions might work, but v0.6.1 is recommended as it seems to be the most stable and runs just fine!</p>
  
<p>Are you tired of manually downloading all of the songs at <a href='https://mdmc.moe/charts'>https://mdmc.moe/charts</a>?</p>

<h2>Well boy do I have (hopefully) a working solution for you!</h2>

<p>This script is lightweight and runs on the Python framework. It fetches metadata from the website listed above, scrolls down to the end of the entire page (around 279 pages or so I believe), and attempts to press the "Download Chart" button for you!</p>

<p>The script will create a folder named "mdmc_all" and attempt to place all files from the web server into that folder. You may need to drag the files manually into Muse Dash afterwards (impossible to be sure where you install stuff)</p>
